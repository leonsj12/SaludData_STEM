# Glosario STEM

| Concepto | Explicación |
|---|---|
| API | Interfaz para solicitar información a un sistema de software. |
| DataFrame | Estructura tabular de pandas. |
| ETL | Extract, Transform, Load. |
| CSV | Formato de datos tabulares separado por delimitadores. |
| Encoding | Forma de representar caracteres como bytes. |
| Parquet | Formato columnar eficiente para análisis. |
| Serie temporal | Datos ordenados cronológicamente. |
| Agregación | Resumen de múltiples registros. |
| Anomalía | Observación estadísticamente inusual bajo una regla definida. |
| z-score | Distancia estandarizada respecto de la media. |
| Baseline | Referencia sencilla contra la cual comparar un modelo. |
| MAE | Error absoluto medio. |
| RMSE | Raíz del error cuadrático medio. |
| R² | Coeficiente de determinación. |
| Reproducibilidad | Capacidad de repetir un análisis siguiendo el mismo procedimiento. |
| Dashboard | Interfaz visual para explorar información. |
| Flask | Framework web de Python. |
| pandas | Biblioteca Python para análisis tabular. |
| Git | Sistema de control de versiones. |
| GitHub | Plataforma para alojar y colaborar en proyectos Git. |
