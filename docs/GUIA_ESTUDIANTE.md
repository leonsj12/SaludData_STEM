# Guía de aprendizaje por etapas

## Etapa A — Ejecutar

Primero lograr que la aplicación funcione.

## Etapa B — Leer

Abrir:

- `app/services/data.py`
- `app/services/analysis.py`
- `scripts/update_data.py`

Leer primero los comentarios y luego el código.

## Etapa C — Experimentar

Cambiar una función pequeña y ejecutar las pruebas.

## Etapa D — Preguntar

Ejemplos:

- ¿Qué ocurre si cambio `;` por `,`?
- ¿Qué ocurre si falta una columna?
- ¿Qué significa NaN?
- ¿Qué pasa si un año está incompleto?
- ¿Qué significa un z-score alto?

## Etapa E — Investigar

Formular una pregunta que pueda responderse con los datos disponibles.

## Etapa F — Comunicar

Toda conclusión debe explicar:

1. qué se observó;
2. con qué datos;
3. qué método se utilizó;
4. qué limitaciones existen;
5. qué no puede concluirse.
